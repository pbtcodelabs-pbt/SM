# 📒 پروجیکٹ نوٹس — سبزی منڈی (SM) + صدام فروٹ منڈی (FM)
> Claude کے لیے: کوئی بھی کام شروع کرنے سے پہلے یہ فائل پوری پڑھیں۔ ہر نئی SM زپ میں اسے اپڈیٹ کریں ("آخری کیفیت" اور "اگلا کام")۔

## دو الگ ریپو — مکمل علیحدگی
- **FM ریپو** = صدام فروٹ منڈی۔ فائربیس ہوسٹنگ پر (`.github/workflows` کی دو فائربیس فائلیں — کبھی نہ چھیڑیں)۔ یہی **ماسٹر** کوڈ ہے، ہر مرمت/نیا کام یہیں۔ اس میں سبزی منڈی کی ایک لائن بھی نہیں ہونی چاہیے۔
- **SM ریپو** = سبزی منڈی (جنرل ایپ، کسی بھی بیوپاری کے لیے)۔ GitHub Pages پر۔ ہاتھ سے نہیں لکھی جاتی — FM سے Claude اپنی طرف بناتا ہے:
  `python3 tools/build_general.py <FM ریپو کا فولڈر> 'SM299TU#004'` (SM ریپو کی جڑ سے) → `index.html`, `sw.js`, `manifest.json`
- جنرل ایپ کی ہر الگ تبدیلی `tools/build_general.py` میں کریں، FM میں نہیں۔
- SM ریپو میں اپنے فونٹ (JameelNoori دونوں) اور اپنا آئیکن (سبزی منڈی بازار + بورڈ) ہیں۔
- جب FM بدلے: صارف FM زپ FM ریپو میں؛ Claude اسی سے SM زپ بھی بنا کر دے (صارف جب چاہے SM ریپو میں اپلوڈ کرے)۔

## مستقل اصول (صارف کی ہدایات)
1. بات چیت ہمیشہ **مکمل اردو** (پاکستانی رسم الخط) میں، مختصر، کم الجھن۔ کاپی کرنے والا متن ہمیشہ الگ کوڈ ڈبے میں۔
2. **صرف زپ فائل** دیں۔ FM اور SM کی زپ **ہمیشہ الگ** — ایک زپ میں دو index.html کبھی نہیں۔
3. **ورژن فارمیٹ** (بغیر وقت، بغیر ڈیش): صدام `FM299TU#257`، سبزی منڈی `SM299TU#003` (تاریخ+مہینہ+دن کے دو حرف+#نمبر)۔ ہر نئی فائل پر نمبر ایک بڑھائیں؛ index.html (APP_BUILD_VERSION)، sw.js (CACHE_VERSION) اور زپ کے نام میں۔
4. کام سے پہلے اپلوڈ شدہ فائل کا ورژن چیک کر کے بتائیں (غلط ایپ مثلاً MCS ہو تو روک دیں)۔ MCS اور پلے سٹور کا کام الگ منصوبہ ہے، یہاں نہیں۔
5. ڈویلپر/سبسکرپشن نمبر **03206793793 (عبدالحفیظ)** — کبھی نہ بدلیں۔
6. کام کے بعد براؤزر میں چلا کر جانچ کریں۔
7. سبزی منڈی میں صدام کا نام، نمبر، آئیکن یا ڈیٹا کبھی نہ آئے۔

## آخری کیفیت
- صدام: `FM299TU#257` — والٹ، وصولی لسٹ (کئی طریقے/نوٹ/رپورٹ)، "ادھار دیا/ادھار لیا" (ٹیبل + یادداشت + پرنٹ/سکرین شاٹ/پوسٹر)، فنگر پرنٹ لاگ ان۔
- سبزی منڈی: `SM299TU#003` — الگ ریپو کا پہلا ورژن۔ رجسٹریشن (دکان، مالک، موبائل، تصویر اختیاری)، ہر جگہ دکان کا نام، صدام کا ڈیٹا صاف، الگ اسٹوریج `SM::`، کلاؤڈ بند (اکیلا صارف + گوگل ڈرائیو بیک اپ)، نیا آئیکن۔

## اگلا کام (منصوبہ)
1. **پیکج (سلاٹس)** — سیٹنگ سے: (1) اکیلا صارف + گوگل ڈرائیو، (2) ایڈمن + 1 ملازم، (3) ایڈمن + 2، (4) ایڈمن + 3۔ ہر پیکج کی الگ ادائیگی۔
2. پیکج 2–4 کے لیے سبزی منڈی کا **اپنا نیا فائربیس** — ہر دکان کا ڈیٹا اس کے موبائل نمبر کے حساب سے الگ۔ تب تک کلاؤڈ بند۔
3. اے پی کے — بعد میں۔
